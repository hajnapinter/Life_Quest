## Legitimate-interest assessment: draft for the controller

Method: identify the purpose, consider less intrusive alternatives, and weigh user impact/reasonable expectations, following the [EDPB guidance](https://www.edpb.europa.eu/documents/guideline/guidelines-12024-on-processing-of-personal-data-based-on-article-61f-gdpr_en).

The app's beneficial purpose is small, user-requested activity suggestions and progress feedback. Minimal recorded targets and activity themes can support it; names, emails, photographs and precise coordinates are not needed in AI prompts. Existing validation, bounded targets, no identity fields, manual rights requests and disclosed recipients reduce risk.

However, a local quest library already exists, so external AI is not the only way to supply usable quests. Upstream reuse for model training is not shown necessary for this app's personalisation. City/country and habit themes remain personal information even without a name. The lack of an in-app AI opt-out and unresolved processor/transfer terms prevent treating this draft as an approved assessment. The controller should decide on a suitable basis and controls before a wider launch; do not tick “GDPR complete”. The user declined changing the model during this task.

## Accessibility findings to resolve separately

All six signed-in screens were measured at 390px: no horizontal page overflow, no app exception, no missing names among visible form fields, and no images missing an alt attribute. Navigation is keyboard-operable and uses two rows of three targets, each about 117×33px. This is not a full assistive-technology certification.

Remaining findings: Home has an H3 but no H1; the navigation focus outline `#E8CFC0` on white measures about **1.49:1**, making keyboard focus too subtle; the design guide's claim that white text on Action `#D4551F` passes normal-text contrast is incorrect (about **4.10:1**, below 4.5:1 for ordinary-sized text). Regular navigation text `#55444F` on selected peach is about **8.16:1**; muted text on the page is about **4.61:1**. These palette/heading changes were not mixed into the requested session repair. Reference: [WCAG text contrast](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) and [focus appearance](https://www.w3.org/WAI/WCAG22/Understanding/focus-appearance.html), the latter a Level AAA criterion. A full VoiceOver/NVDA walkthrough and physical-device testing still require separate execution.
